기존 상품 탐색은 카테고리와 필터부터 선택해야 합니다. Styler는 사용자의 상황, 예산, 스타일을 자연스러운 요청으로 입력하고 관련 상품을 탐색하는 AI 쇼핑 어시스턴트 MVP입니다. 문제 정의부터 화면 설계, 데이터 구성, 배포까지 직접 진행했습니다.

CASE 02 / CONVERSATIONAL EXPERIENCE · TAROT AGENT

Tarot Agent.

ACTUAL DESIGN SCREENS

카드를 먼저 보여주기보다,
사용자의 고민을 이해한 뒤 리딩으로.

타로 에이전트는 사용자가 질문을 선택하거나 고민을 직접 입력하면, 상담 대화에서 맥락을 좁혀 카드 선택과 해석까지 이어지는 경험입니다. 아래 네 화면은 기존에 제공한 실제 디자인 원본으로, 대화 흐름과 인터랙션 구성을 보여줍니다.

01 / ENTRY

질문 시작

주제별 예시 질문 또는 직접 입력

02 / CONTEXT

상황 구체화

대화로 고민의 맥락 확인

03 / INTERACTION

카드 선택

상담 흐름에서 3장 선택

04 / INTERPRETATION

리딩과 후속 대화

선택 결과를 해석하고 다음 질문으로

Tarot Agent · Interactive Demo

별도 제작 중인 타로 에이전트 링크를 받으면 이 영역에 연결합니다.
