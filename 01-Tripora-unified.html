01 / THE CHALLENGE

여행의 시작을
가볍게.

여행 계획을 시작할 때부터 목적지, 날짜, 조건을 모두 정해야 할까? Tripora는 아직 계획이 구체적이지 않은 사용자도 쉽게 여행을 시작할 수 있도록 대화 중심의 진입 경험을 선택했습니다.

DESIGN DECISION 01먼저 고르는 대신,
먼저 말할 수 있도록.

검색 조건과 복잡한 필터를 전면에 두는 대신 입력창을 첫 화면의 중심 CTA로 설계했습니다.

DESIGN DECISION 02제안에서 멈추지 않고,
계획으로 이어지도록.

AI와의 대화를 일정 카드, 지도, 이동 동선까지 이어지는 구조로 연결했습니다.

02 / BRAND IDENTITY
DESIGNING THE FIRST IMPRESSION

여행의 시작을
시각화하다.

라틴어 Ora(문, 입구)와 Aurora(오로라)에서 출발한 브랜드. 여행의 새로운 문을 여는 경험을 심볼과 워드마크에 담았습니다.

#FF5C75
#8C2738
#242424

시안을 만들고, 구성원과 의견을 나누고, 하나의 브랜드로 정리했습니다.

약 2주 동안 3~4개의 로고 후보안을 제작했습니다. 내부 구성원 투표를 거쳐 최종안을 선정하고, 심볼·워드마크·컬러·활용 규정을 브랜드 가이드로 문서화했습니다.

03 / ONBOARDING

취향부터 이해하는
다섯 번의 질문.

여행 유형, 목적, 활동 스타일, 일정 선호, 동행 형태를 묻는 5단계 온보딩. 사용자의 여행 취향을 알아가는 과정을 짧은 선택 흐름으로 구성했습니다.

04 / AI AGENT EXPERIENCE

AI의 응답 과정도
사용자 경험으로.

개발자와 Agent 응답 구조 및 구현 가능성을 논의하며, 응답 상황에 맞는 메시지·로딩 상태·추천 결과 표시 방식을 설계했습니다.

01 / RESPONSE STATES

기다리는 시간도 설명이 되도록

AI가 정보를 살피고 제안을 만드는 과정을 상황별 안내 메시지와 단계적 로딩으로 전달했습니다.

02 / STRUCTURED REPLIES

대화 안에 담긴 여행 정보

여행 제안, 장소 추천, 요약 카드 등 응답의 형태가 달라도 정보가 읽히도록 정리했습니다.

05 / CORE EXPERIENCE

Chat to Plan.

여행을 말하면 일정이 구조화되고, 다시 대화하거나 직접 편집해 수정할 수 있도록. 제품의 핵심 경험을 세 단계로 연결했습니다.
